# Aurora Portfolio

## Aurora Desk — EUR/USD ICT terminal

Open **`/terminal`** for the live desk. It pulls a EUR/USD tape (Yahoo FX when the server can reach it, otherwise a CORS-friendly EURUSDT venue, with a labelled demo fallback) and runs an Inner Circle Trader read:

- Market structure (BOS / MSS), fair value gaps, order blocks & breakers
- Buy-side / sell-side liquidity, equal highs & lows, PDH/PDL/PWH/PWL
- Killzones, Silver Bullet, Judas swing, AMD (Power of Three)
- SMT vs GBP, premium/discount + OTE, 2022 model
- Confluence-scored delivery path with invalidation

Educational mapping — not a broker signal and not financial advice.
